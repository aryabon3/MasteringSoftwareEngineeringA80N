## Kenapa Repo Ini Ada

Karena saya gabut, dirumah kaga ngapa ngapain jadi mending saya buat project ini dan semoga one day project ini tercapai.

## Tujuan

Repo ini ada untuk mengingatkan saya jika saya sudah menjadi Master Software Engineering, yaa buat gabut juga sih sebenernya intinya cuma gabut.

> "You don't truly understand something until you can explain it simply."

Saya nggak menulis jurnal ini untuk terlihat sempurna. Isinya akan berantakan, penuh coretan, kadang saya salah paham di satu entry lalu koreksi diri sendiri di entry berikutnya — dan menurut saya itu justru intinya. Jadi *master software engineer* itu bukan soal tahu segalanya dari awal, tapi soal terus-menerus belajar, jujur sama diri sendiri soal apa yang belum dipahami, dan nggak berhenti memperbaiki cara berpikir.
